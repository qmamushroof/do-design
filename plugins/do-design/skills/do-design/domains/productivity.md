# Productivity
Scope: notes, docs, wikis, task/project management, calendars, email clients, whiteboards, collaboration. Related: saas-dashboard, ai-product, devtools, education, crm-enterprise.
## Users & trust drivers
- All-day desktop users who live in the tool; quick capture on mobile; keyboard-heavy power users vs casual collaborators.
- Trust = never losing work (autosave, offline, version history), speed (<100ms interactions), predictable sync.
- Destroyers: sync conflicts, slow load, data lock-in, notifications noise, cluttered toolbars.
## Must-have patterns
- Editor: slash commands, markdown shortcuts, inline formatting toolbar on selection, block drag handles, autosave indicator.
- Views over same data: list, board, calendar, timeline/table; saved filters and grouping.
- Task row: checkbox, title, assignee avatar, due date (relative + color-independent overdue label), priority, status.
- Command palette and global quick-capture shortcut; full keyboard navigation with discoverable shortcuts.
- Collaboration: live cursors/presence, comments with mentions, resolve threads, share dialog with permission levels.
- Version history with restore; trash with recovery window; import/export (Markdown, CSV, ICS).
## Key screens
- Inbox/home, document/page, project board, list/table, calendar, timeline, search, notifications, share/permissions, workspace settings, templates.
## Visual register
- Range: quiet near-monochrome (Linear, Things, Craft), flexible neutral canvas (Notion), warm playful (Tana, Amie, tldraw).
- Content and user data are the color; UI chrome low-contrast, icons thin and consistent, generous whitespace in editors.
- Motion fast (100-200ms), subtle; no bouncy animations slowing repeated actions.
- Tired default to avoid: pastel kanban cards with emoji, rocket/checklist hero illustrations, dashboards of donut "productivity scores".
## Domain rules
- Dates: locale-aware, explicit year when not current, time zones shown for shared events; week start configurable.
- Overdue/priority never color-only; keyboard and screen reader support for drag-and-drop (move-to menu alternative).
- Optimistic UI with clear sync/offline state and conflict resolution; never silently overwrite.
- Sharing: show who can see a doc before sharing externally; GDPR data export and deletion.
## Anti-patterns
- Ten toolbar buttons visible always; modal dialogs for creating a simple task.
- Fake productivity gamification; streak guilt; AI sparkle buttons on every surface.
- Empty states with only an illustration and no starter template or shortcut hint.
